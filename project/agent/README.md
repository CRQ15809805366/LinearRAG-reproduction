# Agent research records

This directory contains curated operational and research memory for future Agent sessions. It is not a bulk runtime-output directory.

## Entry points

- `BASELINE.md`: current verified runtime boundary, repository invariants, and debugging guidance.
- `experiments/README.md`: registry and recording rules for formal evaluations.
- `decisions/README.md`: index of consequential research and repository decisions.
- `history/`: provenance, import, migration, and recovery records.
- `paper/`: paper source material and recovered experiment parameters.

Machine-generated logs, predictions, metrics, caches, and run outputs belong under `data/output/`. An experiment record here should point to that evidence, state what was actually executed, and separate observations from static analysis and unverified explanations.
