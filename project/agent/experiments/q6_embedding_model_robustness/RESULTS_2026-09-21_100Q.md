## Interpretation and boundary

Mean accuracy spans only `0.825-0.830`, while retrieval behavior varies
substantially. E5 changes 91 Top-5 sets and activates over three times as many
entities as MPNet, yet matches MPNet's mean accuracy. On this fixed 100-question
sample, the result supports the paper's qualitative robustness claim.

It does not reproduce Table 5 numerically: this run uses one dataset, 100 rather
than 1,000 questions, and `qwen3.8-flash` rather than the paper's generation and
evaluation setup. The observed `0.005` accuracy spread is one-question scale and
does not establish a best embedding model. Index timings are warm-cache graph
reconstruction timings and are not cold embedding-index benchmarks.

During resume, model switching exceeded available CPU memory twice. The
experiment-only wrapper was changed to load spaCy before GPU embedding stores,
reducing transient CPU memory without changing retrieval logic; completed model
outputs were resumed rather than rerun.
