# Q4 bounded formal retrieval-quality run: 200 questions

## Status and evidence

Completed on 2026-09-20.

Raw evidence:
`data/output/experiment_results/q4_retrieval_quality/q4-formal-200q-20260920/`

## Scope

- Dataset: Medical, complete 225-passage corpus.
- Questions: 50 fixed-seed questions from each of four task types; 200 total.
- Methods: Vanilla RAG Top-5 and original LinearRAG BFS Top-5.
- Embedding model: local `all-mpnet-base-v2` on CUDA.
- LinearRAG NER model: `en_core_sci_scibert`.
- Evaluator: `qwen3.8-flash`, thinking disabled.
- Metrics: context relevance and evidence recall, adapted from the official
  GraphRAG-Benchmark retrieval evaluator.
- Index state: existing Medical embedding and NER caches were reused. The two
  methods each indexed the shared 225-passage in-memory corpus once; resume
  runs loaded saved retrieval results and did not rerun retrieval.

## Command

```powershell
.venv\Scripts\python.exe experiments\q4_retrieval_quality\retrieval_quality.py --questions-per-type 50 --max-workers 16 --experiment-id q4-formal-200q-20260920
```

The saved final evaluation results contain complete per-question judgments for
both methods.

| Contextual Summarize | LinearRAG | 0.730 | 0.708 |
| Creative Generation | Vanilla RAG | 0.510 | 0.457 |
| Creative Generation | LinearRAG | 0.495 | 0.499 |

Macro averages:

| Method | Context relevance | Evidence recall |
|---|---:|---:|
| Vanilla RAG | 0.658 | 0.611 |
| LinearRAG | 0.703 | 0.685 |
| LinearRAG minus Vanilla | +0.045 | +0.074 |

The Top-5 sets differed on 198 of 200 questions. Mean Top-5 overlap was
`0.346`. Paired per-question outcomes were 26 both improved, 16 both declined,
4 recall up/relevance down, 4 recall down/relevance up, and 150 with at least
one tied metric.

## Interpretation and limits

Executed evidence shows that LinearRAG improved both macro metrics on this
balanced local sample. The largest paired task-level gains occurred on Fact
Retrieval evidence recall (`+0.133`) and Complex Reasoning context relevance
(`+0.175`). Context relevance decreased slightly on Contextual Summarize
(`-0.030`) and Creative Generation (`-0.015`), although evidence recall rose in
both groups.

This result does not numerically reproduce paper Table 4. The local run uses
200 balanced questions and `qwen3.8-flash` as judge, while the paper reports a
different evaluation model and broader baseline table. It supports a bounded
local comparison between Vanilla RAG and LinearRAG, not a ranking against the
paper's unexecuted GraphRAG baselines.
