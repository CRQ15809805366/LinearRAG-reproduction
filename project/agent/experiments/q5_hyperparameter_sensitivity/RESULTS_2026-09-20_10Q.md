## Answer-level result

Every delta and lambda point obtained LLM accuracy `1.0`, containment accuracy
`0.8`, and mean accuracy `0.9`. This ten-question sample therefore has no
answer-level resolving power for selecting a best value or reproducing the
paper's sensitivity curve.

## Mechanism-level result

The delta sweep demonstrably changed the real BFS propagation path:

| Delta | Mean active entities | Mean propagated entities | Top-5 overlap with baseline |
|---:|---:|---:|---:|
| 0.1 | 26.5 | 24.9 | 0.84 |
| 0.2 | 19.5 | 17.9 | 0.82 |
| 0.3 | 12.4 | 10.8 | 0.92 |
| 0.4 | 9.6 | 8.0 | 1.00 |
| 0.5 | 6.6 | 5.0 | 0.94 |
| 0.6 | 3.4 | 1.8 | 0.82 |
| 0.7 | 2.3 | 0.7 | 0.76 |
| 0.8 | 1.6 | 0.0 | 0.74 |
| 0.9 | 1.6 | 0.0 | 0.74 |

This supports the intended mechanism: increasing the pruning threshold reduces
entity propagation. At `0.8` and `0.9`, no non-seed entity survived on average
in this sample. The unchanged answer metrics do not imply that delta had no
effect; nine of ten Top-5 rankings changed at both high-threshold points.

The lambda sweep left entity propagation unchanged, as expected, because
lambda is applied after entity activation during initial passage scoring.
Top-5 overlap with the `0.05` baseline was `1.00` at `0.01`, `0.05`, and `0.1`,
then fell to `0.96`, `0.96`, `0.92`, and `0.90` at `0.5`, `1.0`, `1.5`, and
`2.0`. Seven of ten Top-5 rankings changed at `lambda=2.0`.

## Non-determinism observation

`lambda=0.01` retrieved the same ranked Top-5 passages as the baseline for all
ten questions, but one generated answer string differed. Both configurations
still received identical evaluation scores. Because the retrieval context was
unchanged, this is evidence of generation-side non-determinism rather than a
lambda effect. Future answer-level comparisons must not attribute an isolated
string change to retrieval without checking the retrieved context.

## Interpretation boundary

Executed evidence establishes that the sweep code runs end to end, changes the
intended live parameters, preserves controls, and detects mechanism-level
effects. It does not reproduce Figure 5, establish an optimal delta or lambda,
or test statistical significance. A larger fixed sample is required for the
answer metric to have useful resolution.
