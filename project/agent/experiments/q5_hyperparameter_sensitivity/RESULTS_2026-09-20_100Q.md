`0.850`.

## Repeated-baseline limitation

The identical configuration `delta=0.4, lambda=0.05` was executed once in each
sweep. Retrieval was identical, but the delta-sweep execution scored `0.885`
and the lambda-sweep execution scored `0.850`; 17 generated answer strings
differed. This directly demonstrates material generation/evaluator
non-determinism despite temperature zero. Consequently, small answer-score
differences between lambda points cannot be cleanly attributed to lambda in
this single-run experiment. Retrieval overlap and entity propagation remain
deterministic mechanism evidence.

## Interpretation boundary

The bounded run establishes end-to-end executability and confirms the intended
mechanical effect of both parameters. It supports an intermediate delta region
over the heavily pruned `0.8` setting on this sample, but it does not reproduce
the paper's exact curve or establish a unique optimum. The lambda accuracy
claim is unresolved because repeated-baseline variance is comparable to the
observed between-point differences. The run used `qwen3.8-flash`, not the
paper's `gpt-4o-mini`.
