# Project records

This directory separates the user's private learning workspace from Agent-maintained project context.

- `human/` belongs to the user and holds personal learning notes, plans, and interpretations. Treat its contents as private working material, not externally validated research claims.
- `agent/` holds concise operational guidance and research records used by future Codex sessions. Its current entry point is `agent/BASELINE.md`; formal Q1–Q8 work is indexed in `agent/experiments/README.md`.

Agent-maintained files are written in English to preserve consistent operational instructions. Raw generated outputs stay under `data/output/`; externally readable research material belongs under `research_report/`.
