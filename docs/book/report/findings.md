# 综合结论与未决问题

本地实验表明，LinearRAG 在四数据集各 100 题的 Vanilla RAG 对照中取得更高的已报告答案指标，在 Medical 200 题对照中取得更高的相关性与证据召回宏平均。其索引与检索阶段没有生成式 LLM 调用。加入 HippoRAG 后，方法排名随指标和查询缓存阶段变化，现有证据不支持准确率、检索质量或速度上的普遍领先。

## 结果汇总

| 测量对象 | 本地观察 | 结论边界 |
|---|---|---|
| 对 Vanilla 的答案对照 | 四数据集各 100 题，已报告指标均更高，差异幅度不同 | MuSiQue 等小差异未被确认为稳定收益；未覆盖全部任务与输入 |
| 对 HippoRAG 的答案对照 | HotpotQA 20 题中，HippoRAG 2024 得分更高 | 单次构造语料结果，不构成普遍方法排名 |
| 检索质量 | Medical 200 题两项宏平均更高；12 题三方法中，LinearRAG 召回最高，HippoRAG 相关性最高 | 相关性与参考证据覆盖的排名不同；小语料参考证据未完成标准支持认证 |
| 生成式 LLM 调用 | LinearRAG 索引与检索零调用；HippoRAG 抽取与未缓存问题 NER 存在调用 | 答案生成与评价仍有调用；完整账单未比较 |
| 查询耗时 | 共享输入首次查询为 LinearRAG 更快；问题 NER 缓存后的热检索为 HippoRAG 更快 | 完整 HippoRAG 冷索引耗时缺失；不包含答案生成与评价 |
| 模块消融 | 移除实体传播或 PPR 明显改变上下文；HotpotQA 与 2Wiki 答案均值下降 | MuSiQue、Medical 存在小幅或相反变化，未支持模块在各任务中普遍增益 |
| 参数敏感性与嵌入模型对照 | 参数机制与模型替换后的行为变化可观察；答案分数存在运行波动 | 未确立唯一最优参数或普遍最佳模型 |
| 索引规模 | 完成 250K 与 500K tokens 冷索引，耗时随规模增加 | 各规模单次观测；1M 未完成，未覆盖论文 5M/10M 范围 |
| 单例机制 | 检索支持段落与正确答案可伴随未完成的实体激活或错误链接 | 答案正确不构成中间机制全部正确的证据 |

## 机制解释与结果含义

**图检索改变了上下文选择。** Q3 的模块移除与 Q6 的嵌入模型替换引起大量 Top-5 集合变化，答案均值变化则可能较小。现有结果显示检索行为变化与最终答案分数并不一一对应；各路径对最终回答的独立贡献尚未完全隔离。

**检索质量包含不同测量维度。** Q4 三方法对照中，参考证据覆盖与上下文相关性的最高分来自不同方法。参考项覆盖比例与材料有用程度分别测量，现有结果未建立统一质量排名。

**缓存阶段影响速度与成本解释。** Q2 的首次与热检索排名不同，热检索复用问题 NER。恢复索引时间不包含历史抽取成本，已记录 tokens 也不等于完整账单。现有证据确认调用路径差异与本地阶段耗时，未建立完整冷构建成本对照。

**生成与评价波动限制参数归因。** Q5 相同配置、相同检索结果的两次答案均值分别为 88.5% 和 85.0%，相差 3.5 个百分点。单次参数点的小幅分数差异未被充分隔离为参数效应。

**最终答案与中间机制需独立评价。** Q8 的正确国籍答案伴随未激活 `germany` 或初始实体链接错误。答案正确只能确认该单例的最终输出，不足以验证完整传播或链接路径。

## 未决问题

| 未决判断 | 当前证据缺口 |
|---|---|
| 两种图方法的完整冷构建成本差异 | 缺少统一抽取条件下的 HippoRAG 完整冷索引观测与完整用量范围 |
| 三方法排名的跨输入稳定性 | 缺少独立样本与其他语料条件下的同条件对照 |
| 参数小幅差异的可归因性 | 缺少区分生成、评价波动与参数影响的重复观测 |
| 索引规模增长规律 | 只有两个成功规模点，各一次计时；未覆盖论文来源语料和规模 |
| 案例补回证据的具体路径贡献 | 缺少对中间步骤与得分来源的独立隔离 |

本部分结论以[当前实验状态](../../EXPERIMENT_STATE.md)及各章链接的分项记录和原始证据为依据。上述缺口界定现有结论范围，不构成已执行结果。
