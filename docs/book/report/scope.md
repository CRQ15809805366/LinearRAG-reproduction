# 复现范围与实验条件

本项目基于作者公开实现完成本地运行与有界实验，测量范围包括答案准确率、检索质量、索引与检索效率、模块消融、参数敏感性、嵌入模型替换、索引规模和单例机制。现有结果对应本地输入、模型与执行条件，未覆盖完整论文协议。

## 方法概述

Vanilla RAG 按问题与段落的向量相似度选取 Top-5。LinearRAG 使用默认 BFS 路径，从问题种子实体经关联句子传播，结合实体权重与段落初始分数，通过个性化 PageRank（PPR）排序；没有可用种子实体时采用直接向量检索。HippoRAG 2024 使用 LLM 抽取实体与显式关系，随后构图、链接查询实体并执行 PPR 检索。

LinearRAG 的索引与检索采用本地嵌入、NER 和图计算，没有生成式 LLM 调用。答案生成与 LLM 评价仍调用模型。

## 比较方法

| 方法 | 实现路径 | 比较范围 |
|---|---|---|
| Vanilla RAG | 段落向量相似度 Top-5，随后生成答案 | 是这里的直接向量检索基线，不代表所有普通 RAG 系统 |
| LinearRAG | 发布实现的默认 BFS 实体传播，加上段落初始分数与 PPR 排序 | 本书总结的 Q1–Q8 结果使用这条路径，不来自可选的矩阵检索路径 |
| HippoRAG 2024 | 用 LLM 抽取实体和显式关系，构图后进行实体链接和 PPR 检索 | 原始 `v1.0.0`，带本地兼容补丁；没有运行 HippoRAG2 |

共同的默认嵌入模型为 `all-mpnet-base-v2`，Q6 专门更换了四个嵌入模型。需要答案生成或 LLM 评价的实验使用 `qwen3.8-flash`。HippoRAG 的抽取也使用该模型，采用 GPU 编码和 CPU FAISS。具体来源与引入边界保存在 [LinearRAG 基线记录](../../foundation/LINEARRAG_IMPORT.md)和 [HippoRAG 基线记录](../../foundation/HIPPORAG_IMPORT.md)。

分项记录指出，论文相应回答实验采用 `gpt-4o-mini` 和更大的问题样本。本地模型、样本和协议与论文不同，数值差异未被隔离为检索算法的影响。

## 实验范围

Q1–Q8 对应仓库中的实验代码与结果目录。各范围的执行状态、结果索引和结论条件如下。

| 编号 | 已有实际工作 | 当前缺口或条件 |
|---|---|---|
| Q1 回答准确率 | 四数据集各 100 题的 Vanilla / LinearRAG；另有 HotpotQA 20 题、250 段三方法对照 | 两组输入独立；没有完整论文基线比较 |
| Q2 效率 | LinearRAG 的 2Wiki 100 题检索和三次冷索引；共享 HotpotQA 上两种图方法的首次与热检索 | HippoRAG 完整冷索引耗时缺失 |
| Q3 模块消融 | 四数据集各 100 题，对比完整系统与两种移除模块的变体 | 消融是对论文描述的本地操作化实现 |
| Q4 检索质量 | 完整本地 Medical 225 段、200 题双方法；另有 30 段、12 题三方法 | 小语料只是候选筛选语料，未完成标准支持证据认证 |
| Q5 参数 | 2Wiki 658 段、100 题，共 16 个单因素扫描点 | 每个点一次，没有测参数交互；重复基线有生成和评价波动 |
| Q6 嵌入模型 | 2Wiki 658 段、100 题，四模型对照 | 一个数据集，不能确立普遍最佳模型 |
| Q7 规模 | HotpotQA 250K 与 500K tokens，各一次独立冷索引 | 1M 在 NER 阶段未完成；没有论文 ATLAS-Wiki 5M/10M 对照 |
| Q8 单例 | 既有 2Wiki 缓存上的案例；另有共享 20 段的 LinearRAG / HippoRAG 案例 | 用来观察过程，不能推出总体准确率 |

“完整本地语料”指实验使用了本地登记的整个段落集合，不代表完整公开原始数据集。问题样本规模与可搜索语料规模分别登记。

## 对照条件与输入边界

各次方法对照在其登记范围内使用相同语料与问题，并控制回答和评价条件。跨实验的语料、样本与协议差异不属于受控的方法差异。

三方法小语料对照采用了相同的有序段落和 Top-5 段落预算。但五段相同并不等于上下文 token 数相同：不同方法取出的段落长度可能不同。它是共同的段落数量约束。

有些输入经过构造。HotpotQA 小语料来自所选问题的候选上下文，加上随机来源文档；候选上下文不等于标准支持事实，随机加入的段落也不保证无关。Medical 小语料则经过候选筛选，其中问题和参考信息参与了语料构造；参考信息不直接提供给检索器，但输入本身已经经过筛选。这些条件都限制了结果的推广范围。

Q1、Q3、Q5 分别执行并保存样本与运行记录，其完整系统分数不互相替代。Q5 的重复基线另显示，相同检索结果下的生成与评价仍存在波动。
