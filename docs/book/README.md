# LinearRAG 复现总结

这本书写给希望了解或接手这个项目的人。第一部分交代实际完成的工作、观察结果与结论边界；第二部分从具体问题出发，逐步理解 LinearRAG 的算法、官方实现和本地实验设计。

读完第一部分，应该能回答三个问题：这次复现做到哪里了，LinearRAG 在这些本地条件下表现怎样，还有哪些判断现在做不了。需要重新配置环境时，去看[运行说明](../RUNNING.md)；需要查某次实验的完整输出时，从[实验状态索引](../EXPERIMENT_STATE.md)进入。书稿不重复维护安装步骤和全部运行日志。

## 从哪里开始读

想先了解项目做到了哪里，从[复现范围与实验条件](report/scope.md)开始；想先了解结果，可以读[综合结论与未决问题](report/findings.md)，再回到关心的章节核对条件和数字。想建立或恢复对方法的理解，从第二部分的[如何理解 LinearRAG 算法](resume/algorithm.md)开始，沿着同一个小例子走到代码，再进入实验设计。

第一部分主要回答“做了什么、看到了什么”，报告实验条件、观察结果、机制解释与结论边界。第二部分主要回答“为什么这样做、具体怎样做”，以直觉、例子、公式和真实代码逐步展开。可以根据需要分别阅读，也可以在理解方法后回到报告检查实际观察。

第一部分依据截至 2026-10-02 已登记的实验结果编写。第二部分依据仓库内论文、引入版本与当前代码撰写；教学例子和手工分数会明确说明，不作为实验结果。两部分书稿形成于 2026-10-03。

## 怎样读数字和解释

正文中的表格保留实际观测结果。百分比和小数按注明的精度呈现，原始精度可以从对应证据文件查到。“这批样本里更高”描述这次观察；解释为什么出现差异时，如果没有直接验证，就明确写为可能的解释。

不同实验的语料、问题样本、缓存阶段或评价口径不完全相同。每张表都在自己的条件下阅读，不把各章数字拼成总排行榜。尤其要记住：本地需要生成或 LLM 评价时使用的是 `qwen3.8-flash`；本地 HippoRAG 是原始 2024 版 `v1.0.0`，带兼容补丁，不是 HippoRAG2。
