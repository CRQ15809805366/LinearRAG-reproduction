# Q4 有界正式检索质量结果：200 题

## 状态与证据

于 2026-09-20 完成。

原始证据：`data/output/q4_retrieval_quality/q4-formal-200q-20260920/`

## 范围

- 数据集：Medical，完整的 225 段语料。
- 问题：四类任务各按固定种子抽取 50 题，共 200 题。
- 方法：Vanilla RAG Top-5 与原始 LinearRAG BFS Top-5。
- 嵌入模型：本地 `all-mpnet-base-v2`，使用 CUDA。
- LinearRAG NER 模型：`en_core_sci_scibert`。
- 评价模型：`qwen3.8-flash`，关闭思考。
- 指标：上下文相关性与证据召回率，从官方 GraphRAG-Benchmark 检索评价器改编。
- 索引状态：复用已有 Medical 嵌入与 NER 缓存。两种方法各对共享的 225 段内存语料索引一次；续跑加载已保存检索结果，不重复检索。

200 题中有 198 题的 Top-5 集合不同，平均 Top-5 重合度为 `0.346`。配对的每题结果为：26 题两项指标都提升，16 题两项都下降，4 题召回上升/相关性下降，4 题召回下降/相关性上升，150 题至少一项指标持平。

## 解释与边界

实际证据显示，LinearRAG 在本地均衡样本上提升了两项宏平均指标。任务层面最大的配对提升出现在 Fact Retrieval 的证据召回率（`+0.133`）和 Complex Reasoning 的上下文相关性（`+0.175`）。Contextual Summarize（`-0.030`）与 Creative Generation（`-0.015`）的上下文相关性略降，但两组的证据召回率均上升。

本结果没有数值复现论文表 4。本地使用 200 道均衡问题和 `qwen3.8-flash` 评价，而论文使用不同评价模型和更广的基线比较。本结果支持 Vanilla RAG 与 LinearRAG 的本地有界对照，不能用于排列未实际执行的论文 GraphRAG 基线。
