# Q7 有界规模代理结果：250K 至 500K Tokens

## 执行状态

两次独立冷索引于 2026-09-21 完成：

- `q7-formal-250k-20260921`；
- `q7-formal-500k-r2-20260921`。

两次运行均为 `status=passed`，token 数精确达到目标，运行时使用独立冷缓存，未调用生成式 LLM。临时缓存随后移除，原始运行目录及测量文件仍保留。一次 1M-token 尝试在 NER 阶段未完成，没有可用测量。

## 原始证据

- `data/output/q7_large_scale_efficiency/q7-formal-250k-20260921/`
- `data/output/q7_large_scale_efficiency/q7-formal-500k-r2-20260921/`

## 固定条件

- 来源语料：本地 HotpotQA 段落。
- 论文语料：ATLAS-Wiki，本地规模代理未使用。
- 子集规则：确定性的嵌套语料前缀；仅最后一段可以在分词器边界截断。
- 分词器与嵌入模型：`all-mpnet-base-v2`。
- 测量操作：`LinearRAG.index(passages)`，包含嵌入、NER、图构建和缓存写入。
- 检索参数：`max_iterations=3`、`passage_ratio=0.05`、`iteration_threshold=0.4` 和 `top_k_sentence=1`。
- NER 模型：`en_core_web_trf`。
- 环境：Python `3.9.25`、Torch `2.8.0+cu128`、CUDA `12.8` 和 NVIDIA GeForce RTX 4050 Laptop GPU。
- `NoLLM` 对象在生成模型调用时立即报错。
- 不包含检索、答案生成和答案评价。

## 扩展性观察

观测索引耗时保持在每百万输入 tokens `925.8174124` 至 `974.3120872` 秒的窄区间，相对跨度为 `5.238%`。

| 区间 | token 倍数 | 索引耗时倍数 |
|---|---:|---:|
| 250K 至 500K | 2.0000 | 1.9005 |

从 250K 到 500K，tokens 增加 `2x`，观测索引耗时增加 `1.9005x`。实体、句子、图顶点、图边、缓存大小和 CUDA 峰值内存也随语料规模增大。

仅有两个规模，每个规模只有单次观测，没有重复计时。这两个观测点的索引耗时增幅接近 token 增幅，但不足以确立线性扩展规律或稳定的扩展性分布。

## 失败边界

单独的 1M-token 尝试在 NER 阶段未完成，不纳入已完成结果表，也不能建立 1M 结果。

## 解释与边界

实际证据表明，Q7 实验装置能够构造精确的嵌套 token 规模，执行真实的独立冷索引，并在不调用生成式 LLM 的条件下记录索引与图指标。在 250K 与 500K 两个观测点之间，索引耗时和存储图规模随输入 token 数增大。

这是 HotpotQA 规模代理，不是论文的 ATLAS-Wiki 5M/10M 实验。它没有复现论文索引耗时、确立统计上稳定的线性扩展结论、执行检索或生成，也没有比较 LinearRAG 与 RAPTOR、HippoRAG。
